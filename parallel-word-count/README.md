# Parallel and Distributed Word Count System

Course: COMP 412 – Parallel and Distributed Systems

## Description
This project implements a word count system using serial, parallel, and
distributed programming techniques. The goal is to analyze performance
improvements achieved through parallelism and distributed execution.

## Technologies
- Python 3
- Multithreading
- Multiprocessing
- Git & GitHub

## Project Structure
- src/: Source code
- data/: Input text files
- docs/: Design documents and diagrams

### Serial Word Count

python serial_word_count.py
